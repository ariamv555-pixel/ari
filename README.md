# ari
Soy estudiante de Animación 3D y me interesa el mundo del arte digital y el desarrollo de videojuegos. Me gustaría crear mundos visuales, diseñar atmósferas y dar vida a ideas a través del modelado 3D y la animación. 

Actualmente trabajo con Unity para desarrollar videojuegos y aprender programación en C#. También utilizo Blender para el modelado, la animación 3D, Krita para la creación artística, Substance 3D Painter para trabajar con materiales y texturas, y DaVinci Resolve para la edición de videos
